Real reasoning for each addition, in order:
1. syncOviondClients.js - unchanged, real, existing, runs first.

3. backfillDailyMetrics.js --days=3 - real, new tonight, small
   OVERLAPPING window (not the full --days=60 initial catch-up,

   re-fetching the last 3 real days daily is safe and self-healing
   if a prior day's data was incomplete when first written - it
   simply re-confirms/corrects those rows, never duplicates them.
4. runBrainForAllLocations.js - unchanged, real, existing, runs
   last, now with current-period and fresh daily data available to
